# もちエクIME 0.1.3

Android 7.0以上向け、Sumire Lite派生の日本語キーボードです。
画像検索 → サムネをタップ → 入力欄へ画像URLを挿入できます。Enter・送信は行いません。

## 使い方

1. APKをインストールし「もちエクIME」を開き、キーボードを有効化・選択。
2. 「画像」から検索。☆で端末内のお気に入りに保存、「お気に入り」で表示。
3. 地球アイコンで日本語テンキー／日本語QWERTYを切替。選択は保存されます。

「配列」ボタンを削除し、画像を隠さない☆、大きいタイル、2行タイトル、画像確認時のエラー案内を反映しています。
アルバムは画像を選択、GIFは静止サムネから元GIFのURLを挿入します。

## 注意事項

- 本番版と開発APKは署名が異なります。上書きできない場合、必要な辞書・設定をバックアップしてから開発版をアンインストールしてください。お気に入り等は自動移行しません。
- 通常の日本語変換は端末内。画像検索にはインターネットが必要で、専用検索欄で「検索」を押したときだけ検索語を送ります。投稿文・パスワード・クリップボードを画像検索に送りません。通信基盤のIP等のアクセス記録は残る場合があります。
